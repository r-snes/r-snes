# Introduction

Welcome to the R-SNES documentation!

R-SNES is a Super Nintendo emulator written in Rust. It aims to be decently fast and very accurate, while staying easy to understand. It can also be extended with Lua plugins, which run in a sandbox and only get the permissions you grant them.

> [!NOTE]
> R-SNES is still a work in progress. It runs and passes the full [snes-tests](https://github.com/gilyon/snes-tests) suite, but it can't run commercial games yet.

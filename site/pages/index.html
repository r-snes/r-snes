About the project

What R-SNES is about

R-SNES aims to be a decently fast and very accurate SNES emulator, while staying easy to understand thanks to modern coding standards.

We try to stay performant (low resource usage on your machine) and accurate to our best effort: games should behave exactly as they would on the original console. Each piece of hardware lives in its own Rust crate, documented and tested, so the emulator doubles as a readable reference of how the console works.

The experience is extensible with Lua plugins that can watch and change what happens inside the console, on every CPU instruction or at set intervals. Since plugins can be powerful, each one has to declare the permissions it needs, and you approve them before it runs.

Plugins

Extend the console with a few lines of Lua

A plugin is a Lua file returning a table: the permissions it needs, and the functions the emulator should call.

  1. Write a plugin declaring the permissions it requests.
  2. Load it with File > Load plugin… (Ctrl+P) and review the permissions.
  3. Open a ROM: your plugin starts alongside the game. Press R to run its action.
Write your first plugin Plugin API reference 
-- hello.lua: print the CPU's program counter on demand
return {
    permissions = {
        internal = { cpu = { "registers" } },
    },

    init = function()
        print("Hello, world!")
    end,

    actions = {
        -- run when you press R
        default = function()
            print("PC = " .. rsnes.cpu.pc)
        end,
    },
}

Community

Get involved

R-SNES is open to contributions: features and fixes around the emulator, documentation, tests, plugins, bug reports and ideas. The core emulation is developed by the core team, but minor contributions to it are welcome too. Read our contributing guide to get started.

# Controls and shortcuts

## Keyboard

The default layout is designed for AZERTY keyboards: the SNES buttons sit on the left hand, the D-pad on the arrow keys.

| SNES button | Key |
|:------------|:----|
| D-pad | Arrow keys |
| A | `D` |
| B | `S` |
| X | `Z` |
| Y | `Q` |
| L | `A` |
| R | `E` |
| Start | `Enter` |
| Select | `Right Shift` |

Keys are matched by the letter they type, not by their position, so on other layouts (QWERTY…) use the same letters: they are just less conveniently placed.

## Gamepad

Any controller supported by SDL2 works (Xbox, PlayStation, Switch Pro, most generic gamepads). Plug it in before or while R-SNES is running: it is picked up automatically.

Buttons are mapped by position, so the layout matches the original SNES controller:

| SNES button | Xbox-style controller |
|:------------|:----------------------|
| D-pad | D-pad or left stick |
| B (bottom) | A (bottom) |
| A (right) | B (right) |
| Y (left) | X (left) |
| X (top) | Y (top) |
| L / R | Left / right bumper |
| Start | Start / Menu |
| Select | Back / View |

## Shortcuts

| Action | Shortcut | Menu |
|:-------|:---------|:-----|
| Open a ROM | `Ctrl+L` | File > Open ROM… |
| Close the ROM (or the open window) | `Esc` | File > Close ROM |
| Load a plugin (no ROM running) | `Ctrl+P` | File > Load plugin… |
| Quit | `Ctrl+Q` | File > Quit |
| Pause / resume | `P` | Emulation > Pause |
| Reset the console | `Ctrl+R` | Emulation > Reset |
| Run the plugin's action | `R` | Emulation > Run plugin action |
| Show ROM information | `F1` | View > ROM information |

Every menu entry shows its shortcut, and entries that can't be used right now are greyed out.
